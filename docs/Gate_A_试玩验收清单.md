# Gate A 试玩验收清单

> 版本：2026-10-25 · 对应提交 `69ee74b` · 依据 GDB V1.1 §25 Gate A、D8、§9A、§17.6、§23
> 代码层的检查（Lune 测试、StyLua、Selene、luau-lsp 纯模块与 Roblox 全量、Rojo 构建、CI）已全部通过。本清单只列**必须在 Studio 里亲眼确认**的项目。
> Gate A 没通过之前不开始 Gate B（§25）。

## 0. 启动

```bash
rojo serve
```

1. 打开 Studio，Rojo 插件里 Connect。
2. 单人测试：Play。1 名真人会由 Bot 补到 6 名参与者（练习局）。
3. 多客户端测试：Test → Clients and Servers，选 4 个客户端（技术闭环）或 8 个（玩法验证，可含 Bot）。
4. 输出窗口应出现 `[BreakTheChain] RoundService started` 和 `[Telemetry] round_started ...`。

操作：WASD 移动，Shift 冲刺，鼠标左键 = 开火（人类）/ 扑咬（丧尸），1/2/3 切换武器，R 换弹，E 按住 = 注射解药 / 重连。手机端都有对应按钮。

## 1. 首先确认（如果失败，后面都不用测）

- [ ] 进入后能看到灰盒地图，角色出生在出生点，没有掉出地图。
- [ ] HUD 显示阶段与倒计时，20 秒准备期后进入爆发期。
- [ ] 输出窗口没有红色报错，特别是 `require("./InfectionGraph")` 这类按路径加载模块的报错。

## 2. 追逐与扑咬（A0）

- [ ] 冲刺有耐力条，用完自动停，停下后恢复。
- [ ] 隔离突破选出零号，头上出现 SOURCE 标记，5 秒尸变后变成丧尸。
- [ ] 丧尸扑咬有前摇和短冲刺；手机上能咬中；被咬后看到“尸变中”和倒计时。
- [ ] 两个角色之间站着第三个人时，扑咬不被挡（只有墙会挡）。

## 3. 战斗层（A0.5，§9A）

- [ ] 地图上有手枪、电击枪、弹药箱，走近即拾取；手上能看到武器。
- [ ] 手枪 4 发打倒普通丧尸，零号 5 发；短棍 5 下。
- [ ] 丧尸倒地 4 秒只能爬；没被治愈则化为红色粒子消失，按人数档 6/8/10 秒后在感染区复活。
- [ ] 电击 1.5 秒；5 秒内不能再被电击。
- [ ] 扑咬命中后擒抱 1 秒；这 1 秒内队友开枪或近战能救下，被救者有短暂保护。
- [ ] 丧尸前摇时被击中，扑咬取消。
- [ ] 开枪后，丧尸玩家屏幕边缘出现方向提示。
- [ ] 丧尸跳出地图：可行动时按死亡处理；倒地时被放回原位。

## 4. 感染树、治愈、断链、重连（Gate A 核心）

- [ ] 拿到解药后，靠近一名倒地或被电住的非零号丧尸按住 E，2 秒读条完成后对方变回人类。
- [ ] 对零号按 E 会提示 SOURCE、解药无效，不消耗解药。
- [ ] 治愈一个下游有人的感染者后，下游变成金色“断联”，本人看到 8 秒倒计时和方向箭头。
- [ ] 断联者跑到稳定丧尸旁按住 E 约 1 秒能重连（目标是零号时 1.5 秒）；倒地或死亡时不能重连。
- [ ] 断联 8 秒到期没重连就变回人类，获得 7 秒保护。
- [ ] 断联丧尸死亡后倒计时照常走；到期时在人类出生点以人类身份出现。
- [ ] 两人同时治疗同一目标，只消耗一支解药。
- [ ] 持解药的人被感染后，解药在其完成尸变时掉在地上。

## 5. 撤离与胜负（§13）

- [ ] 最后 90 秒出口打开，有公告和视觉变化。
- [ ] 人类在出口区域站满 2 秒才算撤离；中途被咬会打断。
- [ ] 达到撤离人数（4～7 人局 1 人）时人类胜利，结果横幅显示原因。
- [ ] 人类全部感染、且没有尸变中或断联的人时丧尸胜利；还有断联者时不会提前判负。
- [ ] 时间到而撤离人数不够，丧尸胜利。
- [ ] 结算 8 秒后自动开下一局，零号尽量换人。

## 6. 信息泄露（§17.6，release blocker）

1. Studio 里在聊天框输入 `/btcleak`，客户端会每 10 秒打印它能读到的全部属性和最近 20 条 Remote 载荷。
2. 用人类客户端和丧尸客户端各看一次：
   - [ ] 角色属性里只有 `BTC_State`、`BTC_Combat`、`BTC_Health`、`BTC_RespawnAt`、`BTC_Protected`、`BTC_Root`、`BTC_Grabbed`、`BTC_Grabbing`、`BTC_ParticipantId`，以及玩家上的 `BTC_Stamina`。
   - [ ] 没有任何谁感染了谁、上游、下游、子树大小的信息。
   - [ ] 公开事件里没有剩余人类 / 丧尸总数（§13.4）。
   - [ ] 重连提示只有方向和距离，没有目标是谁。

## 7. 稳定性（D8）

- [ ] **技术闭环**：4 名参与者跑完整局，上面第 2～5 节都出现过。
- [ ] **玩法验证**：至少 8 名参与者（可含 Bot）连续 20 局，没有死锁、没有卡在某个阶段，输出窗口没有 `round_error`。
- [ ] 连续多局后服务端内存没有持续上涨（Studio 的 Developer Console → Memory）。

## 8. 已知还没做的部分

- 没有命中特效、枪口火光、曳光、音效、换弹进度条，只有灰盒和 HUD 文字。
- 撤离者和观战者被移到地图外，没有观战镜头。
- Bot 去拿解药和枪时走直线，可能被墙卡住；去出口走路点。
- 扫描、电力节点、正式地图属于 Gate B。
